# 实琴录音 · 第一批

先录一把最有代表性的琵琶，不必一次录完三种材质。先提交「环境底噪 + 四根空弦中力度各三次」，检查收音质量后再补全。

原始文件放入 `Recordings/pilot/raw/`。不要覆盖 `PipaAudio/`：那里是旧合成引擎的演示，不是真实样本。

## 录音设置

- 推荐原始 PCM WAV，48 kHz、24 bit。已有 44.1 kHz 或更高规格也保留原始格式，不做升采样。
- 单声道即可，立体声保留原始声道。
- 关闭自动增益、降噪、均衡、压缩和混响；不要归一化、剪掉起音或截断尾音。
- 固定设备增益、麦克风位置和坐姿。先试录最强音，避免削波，峰值建议约 −12 至 −6 dBFS。
- 麦克风可从距面板 40–60 cm 开始试录；房间反射重就贴近到 20–30 cm，越近越能反映琴体本身。记录实际朝向与距离，整个录制过程不要移动。
- 每音前留约一秒；每音后等余音自然消失，再留两秒。强音、低音可延长到十秒以上。
- 单音先统一使用「弹」（食指）、常用右手拨弦位置，义甲材质记入 session.md。其他弦保持一致的自然状态，不要有时闷住、有时开放；记录所用方式。
- 不要在余音中口述标签；如需报幕，在文件开头说完后等待数秒再弹。

## 第一次先交这五个文件

每个空弦文件包含三次独立中力度弹奏，不用手工切分。

1. `pipa01_room.wav`：15 秒环境底噪，保持同样设备增益。
2. `pipa01_s4_open_tan_medium.wav`：第四弦（最粗），三次。
3. `pipa01_s3_open_tan_medium.wav`：第三弦，三次。
4. `pipa01_s2_open_tan_medium.wav`：第二弦，三次。
5. `pipa01_s1_open_tan_medium.wav`：第一弦（最细），三次。

文件名里的 `s1`–`s4` 就是第一至第四弦。注意程序内部编号方向相反：`s1` 第一弦（最细，子弦）对应 string 3，`s4` 第四弦（最粗，缠弦）对应 string 0。分析时按这张表对照，不要按数字大小直接对齐。

弦号按实际第一至第四弦记录，避免只写传统弦名造成混淆。录音前调音，并在 session.md 填写实际音名／八度或调音器频率，不要为匹配程序而改变你的定弦。

## 收音确认后补全试验包

- 四根空弦：轻、中、重，每档三次（总计 36 音，包括先交的 12 音）。
- 每根弦选低、中、高三个常用按弦位置，中力度各三次（36 音）。文件名含实际位置，例如 `pipa01_s1_pin05_tan_medium.wav`。`xiang` 表示相，`pin` 表示品，二者分别计数。
- 弹挑、轮指、扫、拂、推拉音各 10–15 秒，分别录文件。
- 一段熟悉的旋律，20–30 秒，作为独立听感验证材料，不用于拟合。

这只是校准试验包，并非最终完整采样音源库。确认发声方案之后再扩充音域、力度层和重复次数，最后录第二、第三把琴。

## 收到录音之后

1. 原件只读保留，分析结果及切分文件另存。
2. 检查格式、声道、电平、削波、底噪、起音与尾音；人工试听确认设备处理和房间反射。
3. 核验实际定弦，对比起音频谱、谐波包络、衰减和强弱音差异。
4. 先做一个弦／几个音的改进试验，对比原录音、当前模型和改进模型。试听时匹配音量，保留未匹配原件。
5. 根据效果决定继续物理参数拟合，还是引入采样起音／多采样混合方案。

基础电平检查（不替代试听，不将普通拨弦录音视为琴体脉冲响应）：

```sh
python3 Scripts/inspect-recordings.py Recordings/pilot/raw --output Recordings/pilot/reports/levels.json
```
